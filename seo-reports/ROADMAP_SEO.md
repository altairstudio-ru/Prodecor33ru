## Метаданные
- Создан: 24-07-2026
- Старт SEO: 24-07-2026
- Горизонт: 3 месяца (до конца октября 2026)
- Статус: В процессе (Месяц 1, Неделя 3)

---

## Общая стратегия

**Цель:** Максимизировать SEO-эффективность через миграцию на Astro + расширение структуры сайта.

**Ключевые направления:**
1. Миграция с React/Vite на Astro (SSG)
2. Расширение до многостраничника (30 страниц: дизайн, ремонт, материалы)
3. Очистка индекса от старого сайта-магазина (см. INDEX_CLEANUP.md)
4. Гео-оптимизация (Владимир + область + 4 города)
5. Контентная стратегия (блог на статике → AltaiR CMS)
6. Техническое SEO (Core Web Vitals, JSON-LD, sitemap)

## Примечания

- **Старый сайт:** магазин «Мартин» (MODX) полностью убираем; тематика «материалы» возвращается страницами /materials/* (позиционирование «полный комплекс»)
- **Меню-дерево:** дизайн / материал / ремонт — в боковом меню (Header.tsx), на главной не разворачивается
- **Блог:** сначала статика (MDX), потом интеграция с AltaiR CMS
- **Гео:** 5 страниц (Владимир, область, Муром, Ковров, Гусь-Хрустальный)
- **Staging:** Vercel Preview (каждый PR/branch)
- **Отзывы:** генерация ИИ + гуманизация
- **В git не коммитить:** данный файл — внутренний рабочий документ
